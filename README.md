# ArquiNova — Estudio de Arquitectura

Proyecto web responsivo desarrollado como parte de la Unidad 1 de la asignatura Aplicaciones Web de la Universidad Politécnica Salesiana.

## Descripción

ArquiNova es un sitio web demostrativo de un estudio de arquitectura que presenta proyectos residenciales, diseño de interiores, servicios arquitectónicos y un formulario de contacto.

El sitio cuenta con cinco secciones: Inicio, Proyectos, Servicios, Nosotros y Contacto.

## Tecnologías utilizadas

- **HTML5:** estructura semántica, navegación, imágenes con texto alternativo y formulario.
- **CSS3:** diseño mobile first, variables, Flexbox, Grid y media queries.
- **JavaScript:** menú adaptable, filtro de proyectos y validación del formulario.

## Estructura del proyecto

- `index.html`: estructura y contenido principal.
- `css/styles.css`: estilos y diseño responsivo.
- `js/main.js`: funcionalidades interactivas.
- `img/`: imágenes utilizadas en el sitio web.

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar `index.html` en un navegador web.

No se requiere instalar dependencias adicionales.

## Pruebas realizadas

- Navegación mediante teclado y foco visible.
- Funcionamiento del menú adaptable.
- Filtros de proyectos.
- Validación de campos del formulario.
- Ampliación del navegador al 200 %.
- Comprobación del contraste principal.
- Validación HTML5 y CSS3 sin errores.
- Revisión visual del diseño en dispositivos móviles y tablets.

## Consideraciones

ArquiNova es un proyecto académico ficticio. Las imágenes son representaciones conceptuales de arquitectura y no corresponden necesariamente a edificaciones construidas.

El formulario realiza validaciones en el navegador, pero no envía datos a un servidor.
